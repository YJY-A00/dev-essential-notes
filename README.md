> 从零搭建、独立部署、故障排查与持续迭代  
> Personal Full-Stack Website · Deployment & Operations Practice

这是一个围绕个人网站建设展开的长期实践项目，记录我从域名与云服务器准备，到 Linux 环境配置、Go 后端开发、MySQL 数据管理、Nginx 部署、HTTPS 配置及网站备案的学习和实践过程。

本仓库主要用于沉淀真实操作过程、技术问题与解决思路，也是我持续学习 Linux、网络、后端开发和 Web 部署的实践记录。

## 系统架构

当前项目采用 Nginx 作为 Web 入口，负责提供前端静态资源，并将 API 请求转发给 Go 后端；Go 后端通过数据库驱动访问 MySQL。

```text
                  用户浏览器
                      |
                  HTTPS 请求
                      |
                Nginx（Web 入口）
                 /           \
                /             \
       静态资源请求           API 请求
             |                  |
       HTML / CSS / JS      Go 后端服务
                                |
                             MySQL
                             数据库
```

- **前端静态资源**：由 Nginx 提供。
- **后端接口**：由 Go 服务处理。
- **数据存储**：使用 MySQL。
- **请求转发**：由 Nginx 将 API 请求转发到 Go 后端。

具体监听端口、目录位置、Nginx 配置和服务管理方式以实际服务器配置及后续部署文档为准。
